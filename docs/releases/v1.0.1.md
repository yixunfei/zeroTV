# zeroTV v1.0.1

## 修复

- 修复 M3U 播放地址同时包含空格和已有百分号编码时的二次转义，保留路径和签名查询参数。
- 修复同频道 HTTP 源失败或超时时覆盖 UDP/RTSP 备用源检测结果的问题。
- 修复首次 EPG 同步后频道索引仍为空、已打开的每日节目表保留旧缓存的问题；手动同步和清空也会刷新相关缓存。
- 频道 Logo 请求携带播放列表指定的 User-Agent 和 Referer。
- 统一本地文件识别及 HLS/DASH 录制可用性判断。
- 完善数据层错误、手动订阅名称、日期时间及未分组标签的中英文显示。

## 改进

- 订阅同步自动采纳播放列表的 EPG 地址（仅在尚未配置时），自动同步任务按过期时间刷新 EPG。
- 扩充回看模板占位符支持。
- 新增贡献指南，修正文档链接及依赖锁文件的仓库源地址。
- 应用版本为 `1.0.1+2`，Android 构建号递增为 `2`。

## 验证

- 新增播放地址编码、备用源检测优先级、EPG 首次刷新缓存的回归测试。
- 本地格式与静态分析通过；51 项纯 Dart 测试、248 项 Flutter 测试全部通过。
- Windows 原生播放器 PCM 音频解码与播放进度冒烟测试通过；未将其视为 Android 视频真机验收。
- 发布附件由 GitHub Actions 构建，包含 Android 分 ABI APK、Universal APK、Windows x64 ZIP 及 SHA-256 校验文件。
